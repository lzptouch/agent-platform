# Agent Skill — frontend-design

> **位置说明**：本目录是 `agent skill/` 项目的 4 个 Skill 之一（其他为 pdf、skill-creator、ralph-loop）。

## Skill 定位

`frontend-design/` 是创建高品质前端界面的 Skill，避免"AI slop"通用审美。

**核心设计原则**：
- **目的优先**：先问"做什么、给谁用"，再谈风格
- **大胆风格**：在 brutalist minimal / maximalist chaos / retro-futuristic / organic / luxury / playful / editorial / brutalist / art-deco / soft pastel / industrial 中选一种
- **避免通用审美**：不用 Inter/Roboto/Arial，不用紫色渐变背景

**技术栈**：
- HTML / CSS / JS
- React / Vue / 任意前端框架
- Tailwind / 任意 CSS 框架
- Motion 库（React）/ CSS 动画
- Google Fonts 配对字体

## 核心原理
1. **目的 > 风格**：先明确产品定位、用户群、技术约束。
2. **概念 > 装饰**：选一个清晰美学方向并贯彻到底。
3. **排版字体先行**：独特字体是差异化的关键。
4. **动画聚焦于"高影响时刻"**：分散动画廉价，集中动画惊艳。
5. **可访问性 + 性能约束**：再炫酷也要 fast & accessible。
