## 2. Python SDK 接口

### 2.1 `SerperClient` 类（`src/serper_service.py:7`）

#### 构造函数

```python
from src.serper_service import SerperClient

client = SerperClient()  # 自动读取 config.yaml
```

无显式参数；初始化时从 `config.yaml` 读取 `serper_api_key`。

#### 方法1：`serper(query: str) -> dict`

调用 Serper API，返回原始 JSON。

**参数**：
- `query: str` — 搜索关键词

**返回**：`dict` — Serper 原始响应（包含 `organic`、`searchParameters` 等字段）

**示例**：

```python
client = SerperClient()
response = client.serper("What happened to Silicon Valley Bank")
print(response["organic"][0]["title"])  # 第一条结果标题
```

#### 方法 2：`_contains_chinese(query: str) -> bool`

判断字符串是否含中文字符（私有方法，但可调用）。

**实现**：`re.compile(r'[\u4e00-\u9fff]+').search(query)`（`serper_service.py:37`）

#### 方法 3：`extract_components(serper_response: dict) -> dict`

从 Serper 原始响应提取核心字段。

**参数**：
- `serper_response: dict` — `serper()` 返回的原始 JSON

**返回**：

```python
{
    'query': str,         # 原始查询
    'language': str,      # 'zh-cn' 或 'en-us'
    'count': int,         # organic 结果数（通常 10）
    'titles': List[str],  # 网页标题
    'links': List[str],   # URL 列表
    'snippets': List[str],# 摘要
}
```

**示例**：

```python
client = SerperClient()
raw = client.serper("小米汽车")
components = client.extract_components(raw)
print(components["links"][:3])  # 前 3 个 URL
```

### 2.2 `WebScraper` 类（`src/web_crawler.py:5`）

#### 构造函数

```python
from src.web_crawler import WebScraper

scraper = WebScraper(user_agent='macOS')  # 或 'Windows'
```

**参数**：
- `user_agent: str = 'macOS'` — UA 类型，影响 Headers

#### 方法 1：`scrape_url(url: str, rule: int = 0) -> str`

抓取单 URL 并提取主内容。

**参数**：
- `url: str` — 目标 URL
- `rule: int = 0` — 提取规则（0=仅 h/p；1=h/p/div）

**返回**：`str` — 主内容（多段用 `\n` 连接）；失败时返回空字符串

**异常**：HTTP 错误时返回空 `Response`，不抛异常

**示例**：

```python
scraper = WebScraper()
content = scraper.scrape_url("https://en.wikipedia.org/wiki/Apple_Inc.", rule=1)
print(len(content), content[:100])
```

### 2.4 `EmbeddingRetriever` 类（`src/retrieval.py:19`）

#### 构造函数

```python
from src.retrieval import EmbeddingRetriever

retriever = EmbeddingRetriever()  # 自动加载 config
```

无显式参数。

#### 方法：`retrievel_embeddings(contents_list, link_list, query) -> List[Document]`

> **注意**：方法名是 `retrievel_embeddings`（少一个 'v'），作者原拼写。

切分 + 向量化 + 召回 top-K。

**参数**：
- `contents_list: List[str]` — 网页内容列表
- `link_list: List[str]` — 对应 URL 列表
- `query: str` — 查询字符串

**返回**：`List[Document]` — Chroma Document 列表（`page_content` + `metadata.url`）

**示例**：

```python

from src.retrieval import EmbeddingRetriever

fetcher = WebContentFetcher("Tencent revenue")
contents, serper_response = fetcher.fetch()
retriever = EmbeddingRetriever()
docs = retriever.retrievel_embeddings(contents, serper_response["links"], "Tencent revenue")
print(docs[0].page_content[:200])
```

### 2.5 `GPTAnswer` 类（`src/llm_answer.py:11`）

#### 构造函数

```python
from src.llm_answer import GPTAnswer

answer = GPTAnswer()  # 自动加载 config（model_name, openai_api_key）
```

无显式参数。

#### 方法 1：`_format_reference(docs, link_list) -> str`

> 私有方法，但常用作转换函数。

把 top-K Document 转为 Prompt 中的 `Web search result` 字符串。

**参数**：
- `relevant_docs_list: List[Document]` — 检索结果
- `link_list: List[str]` — 全集 URL 列表

**返回**：`str` — 形如 `Webpage[1], url: ...:\ncontent...`

#### 方法 2：`get_answer(query, docs, language, output_format, profile) -> AIMessage`

组装 Prompt + ChatOpenAI 流式生成。

**参数**：
- `query: str` — 原始查询
- `docs: str` — `_format_reference()` 输出
- `language: str` — 答案语言（如 `"zh-cn"` / `"en-us"`）
- `output_format: str` — 输出格式约束（可为空）
- `profile: str` — LLM 角色（如 `"conscientious researcher"`，默认）

**返回**：`AIMessage`（LangChain），`answer.content` 为答案字符串

**示例**：

```python
import time
start = time.time()
formatted = answer._format_reference(docs, serper_response["links"])
ai_msg = answer.get_answer(query, formatted, serper_response["language"], "", "")
print(ai_msg.content)
print("耗时:", time.time() - start, "s")
```

### 2.6 `ReferenceLocator` 类（`src/locate_reference.py:4`）

#### 构造函数

```python
from src.locate_reference import ReferenceLocator

locator = ReferenceLocator(gpt_answer, serper_response)
```

**参数**：
- `gpt_answer: str` — 含 `[n]` 引用的 GPT 答案（**必须以 `\nReferences:` 分隔正文与引用块**）
- `serper_response: dict` — `SerperClient.extract_components()` 输出

#### 方法：`locate_source() -> List[dict] | int`

主入口：三段式解析。

**返回**：
- 成功：`List[dict]` —— 每项含 `index, sent, url, source, titles, snippets`
- 失败：`int = -1`（LLM 未输出 `References:` 块时）

**示例**：

```python
import json
locator = ReferenceLocator(gpt_answer, serper_response)
cards = locator.locate_source()
if cards == -1:
    print("LLM 未输出 References 块")
else:
    print(json.dumps(cards, indent=4, ensure_ascii=False))
```

## 6. 错误码与异常处理

| 异常源 | 触发条件 | 处理 |
|--------|----------|------|
| Serper API Key 缺失 | `config.yaml` 中 `serper_api_key: ""` | 调用时 401 报错 |
| OpenAI API Key 缺失 | `config.yaml` 中 `openai_api_key: ""` | ChatOpenAI 初始化失败 |
| LLM 输出无 References | Prompt 模板被修改 / LLM 不遵循 | `locate_source()` 返回 `-1` |
| URL 抓取超时 | `requests.get(timeout=8)` | 返回空 `Response`；进 `error_urls` |
| PDF 文件 | URL 以 `.pdf` 结尾 | 直接跳过，返回空 |
| 内容过短 | `len(content) < 300` | 丢弃不进 `web_contents` |
| Chroma 索引空 | `len(texts) == 0` | `retriever.get_relevant_documents` 返回 `[]` |

## 8. 本章设计原理与依据

### 原理 1：构造函数注入（Constructor Injection）

- **核心思想**：通过 `__init__` 注入依赖，避免内部硬编码。
- **在本项目中的体现**：`WebContentFetcher(query)`、`EmbeddingRetriever()`、`ReferenceLocator(answer, response)` 都通过构造函数注入参数。
- **为什么有效**：便于测试时替换 mock；避免全局状态。

### 原理 2：序列化友好的数据结构

- **核心思想**：核心数据结构（`serper_response`、`reference_cards`）都是 dict，便于 JSON 序列化与跨语言调用。
- **在本项目中的体现**：`reference_cards` 通过 `json.dumps` 直接序列化（`locate_reference.py:119`）。
- **为什么有效**：dict 是 Python 原生支持，最广泛兼容。

### 原理 3：返回类型显式化（Tuple / Optional）

- **核心思想**：函数返回值用类型注解明确表达"可能失败"。
- **在本项目中的体现**：`fetch() -> Tuple[List[str], dict]`、`locate_source() -> List[dict] | int`。
- **为什么有效**：调用方根据类型决定分支逻辑；`-1` 哨兵值易于检测。

### 原理 4：Prompt 与代码解耦

- **核心思想**：Prompt 模板应在配置文件中，不应硬编码在代码里。
- **在本项目中的体现**：`config.yaml` 的 `template` 字段，运行时通过 `PromptTemplate(template=template)` 加载。
- **为什么有效**：调整 Prompt 无需改代码；不同任务可换不同模板。

### 原理 5：Notebook 函数式接口

- **核心思想**：Notebook 适合"逐步执行 + 函数组合"，每个 cell 是一个独立可调用的函数。
- **在本项目中的体现**：`agent_plan`、`retrieval`、`final_answer` 都是 top-level 函数，可在任意 cell 单独调用。
- **为什么有效**：便于实验、调试、教学；比 Class 更直观。

### 原理 6：流式回调（Streaming Callback）

- **核心思想**：长任务通过回调流式输出，避免阻塞。
- **在本项目中的体现**：`StreamingStdOutCallbackHandler`（`llm_answer.py:49`）；Notebook `for chunk in completion`（cell 4327）。
- **为什么有效**：OpenAI Streaming 官方推荐。

### 原理 7：占位符驱动的 Prompt 模板

- **核心思想**：Prompt 用 `{var}` 占位符，由 `PromptTemplate.format()` 动态填充。
- **在本项目中的体现**：`llm_answer.py:51-55` 的 `PromptTemplate(input_variables=[...], template=template)`。
- **为什么有效**：模板与数据分离，便于复用与版本管理。
