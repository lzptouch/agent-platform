## 二、通用约定

1. **每个批次开工前**：先在本目录登记「目标 + 台账条目」，完工后把结果写回 `../design/08` 与 `../roadmap` 对应阶段卡的执行记录。
2. **回归口径**（2026-10-28 批次 03 后）：后端 pytest 不低于 **366 passed / 0 failed**；前端 vitest 不低于 **83 passed**；桌面壳 vitest **45 passed** + typecheck 0；端到端套件不低于 **44 passed**。
3. **门禁**：涉及数据结构的批次必须提供**可回滚**的 Alembic 迁移（`downgrade()` 实跑演练）。
4. **诚实优先**：做不到的事写进本目录，**不要在代码里留"看起来实现了"的分支**。
