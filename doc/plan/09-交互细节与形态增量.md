## 二、范围

### 2.1 循环执行检测（S8 缺口 P2 / `文档.md` §8.4）

| 步 | 动作 | 完成判据 |
|---|---|---|
| 9.1.1 | 检测器：同一工具 + 相同入参在最近 N 轮内重复出现（默认 N=3）即判定疑似循环 | 单元测试可触发判定 |
| 9.1.2 | 命中时在**工具调用前**暂停，产出待确认事件（`loop_detected`），不自动执行 | 事件可回放；工具未被调用 |
| 9.1.3 | 用户可选择「继续执行 / 终止请求」；**终止不删任务**（保留账本与审计） | 两种选择都有用例 |
| 9.1.4 | 终止时终态为 `interrupted`（复用 S4 语义），不新增终态词 | 账本终态一致 |

### 2.2 安全中心界面（`文档.md` §8.6 七项 / §11.1）

| 步 | 动作 | 完成判据 |
|---|---|---|
| 9.2.1 | 新增「安全中心」页（`/admin/security`），七项分组：文件安全（读/写/删）、命令安全（按前缀）、网络安全（远程 HTTP 默认关）、工具启停、敏感目录、审批记录、沙箱状态 | 页面可达，七组可展开 |
| 9.2.2 | 规则增删改走现有 `PUT/DELETE /permissions/rules`；决策记录走 `GET /permissions/decisions` | 与后端端点一致，无新端点 |
| 9.2.3 | 沙箱状态显式展示 `level=policy_only` 与替代机制说明 | **不夸大**（诚实标注） |

### 2.3 资料库与"待确认"编辑（`文档.md` §8.5）

| 步 | 动作 | 完成判据 |
