## 二、桌面壳的构成（`frontend/desktop/src/`）

| 模块 | 职责 | 关键事实 |
| --- | --- | --- |
| `main/index.ts` | 启动编排 | 顺序：单实例锁 → 清孤儿 → 启动页/托盘 → **spawn 后端 sidecar 并等握手** → 引导主窗口 → 注册热键/IPC/更新/电源事件 |
| `main/backend.ts` | 后端 sidecar 编排 | spawn → 握手（读 stdout 的 `AGENT_DESKTOP_READY`）→ 探活循环 → 失败重启 → 优雅退出；握手后写 `run-state.json`（孤儿回收依据） |
| `main/backend-events.ts` | 事件桥 | 把后端 SSE 解析成 `BackendEvent`（纯函数，可单测）；支持 `after_id` **断线续传** |
| `main/window.ts` | 窗口 | 启动页 → 主窗口；后端未就绪时**直接显示错误页**（不静默失败）；`loadWithRetry` 重试 |
| `main/paths.ts` | 路径解析 | 打包态 = `process.resourcesPath`；开发态 = **向上查找 `package.json`**（不依赖编译产物层级） |
| `main/tray.ts` | 托盘 | 托盘图标与菜单 |
| `main/shortcuts.ts` | 全局快捷键 | 注册/释放封装 |
| `main/notifications.ts` | 系统通知 | 通知内容构造 |
| `main/updater.ts` | 自动更新 | **S8 诚实化**：无签名证书与发布通道 → **明确不做自动更新**（`publish` 段为空时不发起检查），并删除「仅接受已签名更新包」的误导注释 |
| `main/ipc.ts` | IPC | 白名单式参数校验（单测覆盖） |
| `main/state.ts` | 后端状态机 | `starting/ready/degraded/crashed/stopped` |
| `preload/index.ts` | 预加载 | 暴露 `agent:backend-state` / `agent:backend-event` / `agent:open-run` 等受限通道 |
| `shared/protocol.ts` | 协议常量 | 通道名与环境变量名（`AGENT_DESKTOP*`） |

**壳测试网**：`frontend/desktop/vitest.config.ts` + 4 个测试文件（事件解析 / 状态机 / 路径 / IPC 白名单）= **27 例**，typecheck 0 错误。

## 三、壳与后端的耦合方式

| 项 | 事实 |
| --- | --- |
| 进程模型 | 壳（Electron 主进程）+ 后端（Python sidecar 子进程），**同机、不同进程** |
| 端口 | 后端监听**随机空闲端口**（回环），端口与令牌写 `run-state.json` |
| 鉴权 | 桌面态后端受**会话令牌 + Host 白名单**守卫；未授权请求 → **401 + 统一错误体**（S1 修复了此前返回 500 的缺陷） |
| 引导 | 壳请求 `/__desktop/bootstrap?t=<nonce>` → 后端校验一次性 nonce → 下发 Cookie → 302 回 `/` → 前端从 `frontend/dist` 加载 |
| 静态资源 | 后端托管 `frontend/dist`（含 `splash.html`），单端口对外 |
| 前端连接 | 前端走同源 `/api/v1/**`（Cookie 携带会话）；开发态 Vite 代理到本地后端 |
| 孤儿回收 | 启动时读 `run-state.json` 里的 pid → 结束残留进程 → 删除文件；**强杀后残留属预期**，下次启动回收 |
| 电源事件 | `suspend` → 状态置 degraded；`resume` → 重新探活 + 调 `resume-scan` 补跑错过的定时任务 |

## 四、打包与发布链路

| 环节 | 事实 | 工具 |
| --- | --- | --- |
| 前端产物 | `frontend/web/vue-element-plus/dist` → 拷贝到 **`frontend/dist`**（含 `splash.html`） | `frontend/scripts/build-frontend.mjs` |
| Python 运行时 | 官方 portable Python（GitHub 发布）在受限网络不可达 → 提供**离线兜底**：用仓库 `backend/.venv` 组装 **standalone 布局**（`runtime/python.exe` + `Lib/site-packages` + `agent/`） | `scripts/stage-runtime.mjs --from-venv` |
| 运行时依赖 | `alembic.ini` **必须**随运行时复制（缺失 → 迁移失败 → 启动中止） | 同上 |
| 打包 | `npx electron-builder --win [--dir\|nsis]`；产物 `frontend/desktop/release/win-unpacked`（约 1.1GB） | `scripts/build-desktop.mjs` |
| 运行时依赖声明 | `electron-updater` 必须在 **`dependencies`**（放 devDependencies → 打包后 asar 缺失 → 主进程启动即崩） | `frontend/desktop/package.json` |
| 打包后自检 | 产物完整性 → 握手 → `run-state` → 存活探针 → 401 统一错误体 → 强杀残留 → **重启回收孤儿** | `scripts/verify_desktop_package.py`（**9/9 通过**） |
| 体积预算 | 运行时 ≤350MB / 前端 ≤30MB / 壳 ≤120MB，超出在构建日志告警（`--strict` 可阻断） | `scripts/build-desktop.mjs` |
| 运行时自检脚本 | 逐路由检查「是否渲染出内容」+ 跨路由比对**侧栏是否恒定** | `scripts/verify_desktop_routes.mjs`、`scripts/verify_sidebar_stable.mjs` |

**遗留（诚实标注）**：① 打包体积 1.1GB（运行时 813MB）**超预算**，需依赖裁剪（`../plan/06`）；② 安装包**未签名**（`../plan/06`）；③ 自动更新**明确不做**（无证书与发布通道）。

## 五、暴露面与边界

| 项 | 事实 |
| --- | --- |
| 绑定 | 后端默认只听 **回环**（S1 起 `host` 默认 `127.0.0.1`） |
| CORS | 未显式配置 `CORS_ORIGINS` 时**白名单为空**（不再回落 `["*"]`） |
| 错误体 | 统一错误体（`code` / `message` / `detail` / `request_id`），响应头带 `X-Request-ID` |
| 权限 | 工具调用统一过**权限引擎**（allow/ask/deny）；ask 只在**审批通道活跃**时阻塞，无通道立即拒绝（绝不静默放行） |
| 无人值守 | 定时任务触发的 run，ask **直接降级为 deny**（不挂起等待审批） |
| 敏感信息 | 写文件与产物会做敏感扫描（正则 + 熵值），三种处置：allow / allow_and_encrypt / deny |

## 八、核对方式

```bash
# 壳构建与单测
cd frontend/desktop && npm run build && npm run typecheck && npx vitest run

# 打包（需 npmmirror 镜像）
cd frontend/desktop && ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ \
  ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/ \
  npx electron-builder --win --dir

# 打包产物自检
cd backend && ../backend/.venv/Scripts/python.exe ../scripts/verify_desktop_package.py

# 运行时自检（需应用带 --remote-debugging-port 启动）
node scripts/verify_desktop_routes.mjs --port 9788
node scripts/verify_sidebar_stable.mjs --port 9788

# 端到端（桌面部分）
cd backend && .venv/Scripts/python.exe -m pytest ../tests/desktop -q
```
