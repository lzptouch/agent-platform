| 风险（OWASP API Top10 2023） | 现状 | 已防护 | 未防护 |

| **API1 BOLA** | ⚠ 无 user 概念，资源全局可见 | 权限规则按作用域判定（管理面） | 无对象级授权 |
| **API2 认证失效** | ✅ 桌面形态全覆盖 | nonce 引导 + HttpOnly Cookie + 令牌 Header + Host 白名单 + 常量时间比较 | — |
| **API3 BOPLA** | ✅ 输入校验 + 统一错误体 | Zod 配置校验 + Fastify schema + 错误体四字段 | — |

| **API9 库存管理** | ✅ 上传限制 | 50MB/100MB + 扩展名白名单 | 无配额与去重 |
| **API10 不安全消费** | ⚠ 本地子进程执行 | 命令黑名单 + 超时 + rlimit + 写路径白名单 + 路径穿越拦截 | 无容器隔离（诚实标注）；Windows 无 rlimit |
