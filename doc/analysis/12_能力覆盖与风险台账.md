## 〇、平台溯源

本平台整合自三个学习项目：**agent skill**（Skill 注册与执行）、**MCP**（Model Context Protocol Server）、**webResearch**（RAG + Web 检索 + 销售助手 Agent），并在此后叠加了 **WorkBuddy 能力扩展**（双模式会话 / Skill 团队 / 定时任务 / 运行账本）与 **S0~S8 阶段化整改**（桌面端、权限引擎、工作空间、运行干预、上下文成本、扩展三层、自动化闭环、交互收尾）。

当前能力面以本篇 §1 为准；历史逐项对照不再维护。

## 三、安全专项

| 风险（OWASP API Top10 2023） | 现状 | 已防护 | 未防护 |
| --- | --- | --- | --- |
| **API1 BOLA** | ⚠ 无 user 概念，所有资源全局可见 | 权限规则按作用域（tool/file/command/network/action）判定 | 无对象级授权 |
| **API2 认证失效** | ⚠ 桌面形态有会话令牌 + Host 白名单；Web 形态单机无鉴权 | 桌面守卫（401 统一错误体） | Web 形态无鉴权（单机形态可接受） |

| **API4 资源消耗** | ⚠ 有并发预算但无限流 | `exec_timeout=180`、`schedule_max_concurrent=2`（交互路径同预算，超限 `busy`） | 无请求级限流 |
| **API5 功能级授权** | ⚠ 无 RBAC，但有规则化三态权限 | 权限引擎（allow/ask/deny）+ 最小权限（角色工具集上界） | 无用户角色体系 |

| **API8 安全配置** | ✅ CORS 已白名单化（未配置即空） | CORS 收紧、Host 白名单、请求 ID | 无安全响应头 |
| **API9 库存管理** | ✅ 上传有大小与类型限制 | 单文件 50MB / 单请求 100MB + 扩展名与 MIME 白名单 | 仍无配额与去重 |
| **API10 不安全消费** | ⚠ 代码执行为本地 subprocess，非沙箱 | 命令黑名单 + 超时 + 权限引擎拦截危险命令 + 批次 01 进程级边界（资源限制 / 输出上限 / 启动前逃逸拦截 / 网络出口开关） | 无容器隔离（`sandbox.level=policy_only` 诚实标注；Windows 无 rlimit） |
