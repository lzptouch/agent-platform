> **依据**：现状取自 2026-10-26 对 `apps/ui/src/` 的盘点；目标取自仓库根 `文档.md` §8（交互逻辑参考）与 §11.6（结果区四视图）、`doc/reference/01-桌面竞品交互对标.md` 的 45 条交互模式目录。

## 3. 关键界面线框

### 3.1 权限审批卡（新增，S2）

```
┌────────────────────────────────────────────────────────┐
│ ⚠ 需要确认 · 高风险                                     │
│ 工具：builtin.fs.write_file                             │
│ 目标：C:/Users/me/Documents/预算.xlsx                    │
│ 理由：超出当前工作空间（可写根：D:/work/wb-20261026-x1） │
│ ┌────────────────────────────────────────────────────┐ │
│ │ 预览：将被写入 1 个文件（约 42KB）                  │ │
│ └────────────────────────────────────────────────────┘ │
│ [ 仅本次允许 ] [ 本工作区始终允许 ] [ 拒绝 ]           │
│ ⌛ 120s 后自动拒绝                                       │
└────────────────────────────────────────────────────────┘
```

**规则**：`critical` 风险不提供"全局始终允许"；超时按拒绝；拒绝后模型收到明确原因。

### 3.2 运行中干预（S4）

```
输入区（running 态）：
┌────────────────────────────────────────────────────────┐
│ 当前命令执行中：python build.py（已运行 12s）            │
│ 追加的指令将在当前命令结束后生效  [仍然停止]              │
├────────────────────────────────────────────────────────┤
│ 输入补充指令…                            [追加] [停止]   │
└────────────────────────────────────────────────────────┘
```

**诚实提示是硬要求**：阻塞式执行器无法中断正在跑的命令，UI 不得显示"已生效"。

### 3.3 变更视图（S3）

```
└─ D:/work/wb-x1/data.csv         修改  +1 −1    [查看] [回退]
```

### 3.4 空态与首任务引导

保留现状的空态 hero + 能力 Chip（已对齐 WorkBuddy 首页结构），**追加**："选择工作空间"入口与"权限档位"提示，避免用户第一任务就撞上审批弹窗。

## 一、这批解决什么

`analysis/12` §2.3 与 `analysis/06` §7 列出的**前后端契约差异**，本质是**后端语义变了、前端没跟上**：

| 差异 | 后端 | 前端 | 用户可见后果 |
| --- | --- | --- | --- |
| `done.status` | 发送 `status`（含 `awaiting_approval`） | `DoneEv` 未声明不消费 | 无法区分「完成」与「待审批」 |
| `busy` 事件 | 并发满时发送 | `AgentEvent` 联合类型**缺 `busy`** | 用户只看到「流突然结束」，不知道是并发满 |
| `memory_item` 事件 | 记忆工具调用时发送 | 联合类型**缺** | 记忆行为不可见 |
| `references` vs `reference_cards` | 两个不同字段 | 分别消费，无统一抽象 | 两种引用渲染逻辑 |
| 上传白名单 | 后端 `core/uploads.py` + 环境变量可覆盖 | 前端 `upload-policy.ts` **另存一份** | 三方不一致 → 前端放行后端拒绝 |
| `/metrics` 口径 | `runs_today` 实为「最近 24 小时」 | 前端按「今天」展示 | 数字对不上 |
| SSE 重连 | — | 无限重订阅，无退避无上限 | 网络异常时打满 CPU |
