### 2.1 后端（`backend/app/`）

| 交付物 | 文件 | 说明 |
|---|---|---|
| Sidecar 启动器 | `app/desktop/launcher.py` | 自绑 loopback socket（`bind(("127.0.0.1",0))` 消除端口竞态）+ `AGENT_DESKTOP_READY` 握手行 + uvicorn 预绑定套接字启动；uvicorn 日志走 stderr，stdout 只留握手行 |
| 会话引导与访问边界 | `app/desktop/bootstrap.py` | 一次性引导 nonce（`/__desktop/bootstrap?t=`，用后即废）→ HttpOnly+SameSite=Strict Cookie；常驻令牌只经 `X-Agent-Desktop-Token` header；Host 白名单（仅 `127.0.0.1`/`localhost` + 本进程端口） |
| 桌面事件总线 | `app/desktop/events.py` | 线程安全环形缓冲（200 条）+ `after_id` 补发；SSE 用轮询（与 `runs.py` 的 DB-tail SSE 同构） |
| 桌面端点 | `app/api/v1/desktop.py` | 12 个端点（status / preferences GET+PUT / workspace GET+PUT / events / components / shutdown / permissions GET+PUT / decision / resume-scan） |
| 三态权限引擎 | `app/services/permissions.py` | deny / ask / allow 按工具类别；判定顺序 **动作→路径→工具→兜底**（高危动作优先，避免「工作区内 allow」放行批量删除）；档位聚合 readonly/ask/allow |
| 桌面配置服务 | `app/services/desktop_service.py` | `desktop_preferences` 单行读写 + 工作区校验切换（立即生效）+ 运行态快照 + 组件探测 |
| 工作区解析 | `app/core/workspace.py` | 进程内可变工作区（运行时切换），`is_in_workspace` 供信任分层判定 |
| 配置扩展 | `app/core/config.py` | `user_data_dir`/`runtime_root`/`builtin_skills_dir`/`frontend_dist_dir`/`default_workspace_dir`/`cors_origin_list` 属性；桌面字段经 `AGENT_*` 环境变量读取 |
| 数据模型 | `app/db/models.py` | 新增 `DesktopPreferenceRow`、`PermissionRuleRow`；`RunRow` 增补 5 个用量字段（prompt/completion tokens、llm/tool calls、estimated_cost） |

## 6. 如何运行 / 构建

```bash
# 后端（Web 形态，行为与改造前一致）
cd backend && ./.venv/Scripts/python.exe -m uvicorn app.main:app --port 8001

# 后端（桌面模式：注入 AGENT_* 环境变量后由壳拉起；手动模拟）
cd backend
set AGENT_DESKTOP=1
set AGENT_DESKTOP_TOKEN=<32字节hex>
set AGENT_DESKTOP_BOOTSTRAP_NONCE=<32字节hex>
./.venv/Scripts/python.exe -m app.desktop.launcher
# → stdout 打印一行 AGENT_DESKTOP_READY {...}

# 桌面壳（开发态，需先装依赖并构建）
cd frontend/desktop && npm install && npm run build && npm start

# 一键打包（需先准备 portable 运行时）
node scripts/build-desktop.mjs --platform win --arch x64 --publish never
```

## 8. 实现时发现并修正的设计偏差

> 实现过程中对照代码修正了设计文档的口径，这些修正已同步回设计文档。

| 发现 | 修正 |
|---|---|
| 权限判定顺序若按「路径→动作→工具」，工作区内的批量删除会被路径规则放行 | 改为**动作→路径→工具**（高危动作优先），已同步 `05` §1.3 |
| 握手 JSON 若回显 token 会随 stdout 落日志（违反密钥不入日志） | 握手行**不含令牌**；改为**双令牌**（一次性引导 nonce + 常驻 header 令牌），已同步 `03`/`04` |
| electron-builder `output:dist` 与 `files:dist/**` 同名冲突；运行时进 asar 无法 spawn | 输出改 `release/`、运行时/前端走 `extraResources`，已同步 `02` §7.2 / `03` §9.1 |
| `vite.config.ts` 是 `sourcemap:true`，打包需关闭避免附带源码映射 | 已写入 `02` §7.3 构建期禁令 |
