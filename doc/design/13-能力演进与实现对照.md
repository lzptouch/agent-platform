## 二、仍需长期记住的设计决策（来自这四个阶段）

| 决策 | 理由 | 现在的落点 |
| --- | --- | --- |
| 真相在 SQLite，不在浏览器存储 | 多端/多进程要看到同一份状态 | `analysis/04` §一 |
| 调度用「表为真相、job 为投影」 | jobstore 无法表达幂等槽位与租约 | `analysis/08` §九 |
| 不用 `SQLAlchemyJobStore` | 幂等 + 租约 + 退避三项语义落不进 jobstore | `analysis/08` §九 |
| SSE 用 fetch + `ReadableStream` 自研，不用 `EventSource` | 需要 POST + 自定义头 + 断线续订游标 | `analysis/06` §十 |
| 主链路是 function calling 循环，不是 plan→action→reflection→answer | 反思只是可选分支 | `analysis/03` §六 |
